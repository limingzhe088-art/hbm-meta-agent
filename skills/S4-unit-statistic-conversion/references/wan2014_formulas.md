# Wan et al. (2014) 公式 S1–S7 —— 中位数/四分位数/极值 → 均值与标准差

> **来源**：Wan X, Wang W, Liu J, Tong T. *Estimating the sample mean and standard deviation from the sample size, median, range and/or interquartile range.* BMC Medical Research Methodology 2014;14:135. doi:10.1186/1471-2288-14-135
> **用途**：S4 阶段把原文只报告"中位数 / IQR / 极值"的浓度数据，转成可参与加权合并的均值与标准差，进而转成 GM。
> **保真声明**：本文件与 `scripts/wan_convert.py` 严格按原文公式实现。**任何算法改动都必须走版本变更并留存新旧对照。**

---

## 1. 符号表

| 符号 | 含义 |
|---|---|
| `n` | 样本量 |
| `min` / `max` | 最小值 / 最大值 |
| `Median` | 中位数 |
| `q1` / `q3` | 第一 / 第三四分位数（P25 / P75） |
| `Mean` | 算术均值 |
| `SD` | 算术标准差 |
| `Φ` | 标准正态分布函数 |
| `q(p)` | 标准正态分位数（`q(0.75) = 0.6745`） |
| `ξ` | 论文中的中间量：`ξ = 2·Φ⁻¹((n − 0.375)/(n + 0.25))`（即 `2·q((n−0.375)/(n+0.25))`） |

**常数**（与原文一致，保留 4 位小数）
`q(0.75) = 0.6745`　`2·q(0.75) = 1.349`　`4·q(0.75) = 2.698`　`2·q(0.75)·√2 = 1.9079`

## 2. 公式全表（原文定义）

| 编号 | 已知信息 | 估计量 | 公式 | 备注 |
|---|---|---|---|---|
| **S1** | `n`, `min`, `max`, `Mean` | SD | `SD = (max − min) / ξ` | 用**均值**范围法 |
| **S2** | `n`, `min`, `max`, `Median` | SD | `SD = (max − min) / ξ` | 用**中位数**范围法，ξ 同上 |
| **S3** | `min`, `max`（无 n） | SD | `SD = (max − min) / (2·q(0.75)·√2) = (max − min) / 1.9079` | 缺 n 时的 **S3**（也称 S3），最粗略 |
| **S4** | `n`, `q1`, `q3`, `Median` | SD | `SD = (q3 − q1) / η`，其中 `η = 2·Φ⁻¹((n − 0.375)/(n + 0.25))` | 用**中位数** IQR 法 |
| **S5** | `n`, `q1`, `q3`, `Mean` | SD | `SD = (q3 − q1) / η`，η 同上 | 用**均值** IQR 法 |
| **S6** | `q1`, `q3`（无 n） | SD | `SD = (q3 − q1) / (2·q(0.75)) = (q3 − q1) / 1.349` | 缺 n 时的 IQR 法 |
| **S7** | `n`, `q1`, `q3`, `Median` | SD | `SD = (q3 − q1) / (2·Φ⁻¹((0.75n − 0.125)/(n + 0.25)))` | 论文提出的**新估计量**，对偏态更稳 |

**配套的均值/中位数估计**

| 场景 | 位置估计量 |
|---|---|
| 只有 `Median` + `IQR` | 用 `Median` 作为中心 |
| 只有 `Median` + `Range` | 用 `Median` 作为中心 |
| 只有 `Mean` + `Range` / `IQR` | 用 `Mean` 作为中心 |
| 只有 `Median` 与极值、无均值 | 中心 = `Median` |

> 本工作包统一约定：**中心值取原文报告的那个量**（有均值用均值，否则用中位数），不做二次校正。该约定写入 `conversion_params` 留痕。

## 3. ⚠️ 关于 ± 号的重要说明（必须知晓）

Wan 2014 的 S1–S5 在论文中以 **`±`** 形式给出（即分母写成 `ξ` 或 `η`，其展开含 `±` 分支），对应两个变体：

| 变体 | 分母 | 特点 |
|---|---|---|
| **减号变体（conservative）** | `ξ₋` / `η₋` | 随 n 增大而**收缩**；n 很小时可能趋于 0，导致 SD 被高估 |
| **加号变体** | `ξ₊` / `η₊` | 随 n 增大而**放大** |

**本工作包的实现约定**：采用**减号变体**，理由：
1. 它是文献中最广泛采用的实现（与主流 meta 分析工具一致）；
2. 保守方向与"不夸大精度"的原则相容。

**必须同时输出 `wan_variant` 字段**（`minus` / `plus`），并在 `conversion_params` 中登记，使该选择**可审计、可切换**。
另对 S4/S5 的 `η` 做**退化保护**：若 `η ≤ 0` 或 `η` 非有限值，不返回估算值，返回 `FAILED` 并要求回退到其他公式或交人工（见 §5）。

### 3.1 ★ 分母的渐近行为（易误用，务必理解）

各公式的分母随样本量的行为**完全不同**，这直接决定"有 n 与无 n 时结果能差多少"：

| 公式 | 分母 | n=2 | n=10 | n=100 | n=1000 | 大 n 极限 |
|---|---|---|---|---|---|---|
| **S4 / S5** | `η = 2Φ⁻¹((n − 0.375)/(n + 0.25))` | 1.349 | 3.288 | 5.0 | 6.9 | **→∞ 发散** |
| **S7** | `2Φ⁻¹((0.75n − 0.125)/(n + 0.25))` | — | ~1.29 | 1.330 | 1.345 | **→1.349** |
| **S6** | `2q(0.75) = 1.349` | 1.349 | 1.349 | 1.349 | 1.349 | 常数 |
| **S3** | `2q(0.75)·√2 = 1.9079` | — | — | — | — | 常数 |

**由此推出的三条重要结论**：

1. **S7 收敛到 S6**（不是 S4）。n 越大，S7 与 S6 越接近。因此"原文给了 n"时用 S7 与"没给 n"时用 S6，结果差别很小——这解释了为什么缺 n 的损失在 IQR 法里可以接受。
2. **S4 恒给出比 S6 更小的 SD**（因 `η(n) ≥ 1.349`）。n 越大差距越大：n=100 时 S4 的 SD 只有 S6 的约 27%。**因此 S4 与 S6 绝不可互换**，公式选择必须严格按"是否有 n"。
3. **无 n 的代价在范围法里更严重**：S3 的分母 1.9079 与 S1/S2 的 `ξ(n)` 在大 n 时相差更多，SD 被系统性高估。

**实践含义**：若原文报告了 IQR 但没给 n，用 S6 的偏差相对可控；但若能用同研究的其他部分反推出 n，**应优先补 n 后用 S4**。该判断记入 `notes` 并交 GATE-4。

## 4. 适用范围与失效条件

### 4.1 成立前提

| 前提 | 说明 | 违反后果 |
|---|---|---|
| 数据近似**正态**（或至少对称） | 公式基于正态分布的分位数关系 | 偏态数据下 SD 被低估，S7 相对更稳 |
| 样本量**中等以上**（原文建议 n ≥ 25） | `ξ`/`η` 的推导依赖次序统计量近似 | n 小（< 25）时误差显著放大 |
| `min`/`max` 不是**离群值** | 范围法对离群值极敏感 | SD 被严重高估 |
| `q1`/`q3` 是**真四分位数** | 不是 P5/P95，不是 `Mean±SD` | 完全错误 |
| 中心值确实是均值或中位数 | 不是几何均值 | 见 §4.2 |

### 4.2 ★ 首要前提：不得对已在对数尺度的数据使用 Wan

**这是本工作包最容易犯、后果最隐蔽的错误。**

| 情形 | 正确做法 | 错误做法 |
|---|---|---|
| 原文报告 **GM + GSD** | **直接取用**，`conversion_path = reported_GM`，不做任何估算 | ❌ 把 GM 当 AM、GSD 当 SD 再套 Wan |
| 原文报告 **GM + 范围/IQR** | 可对 `ln` 值使用 Wan（若原文同时给出对数尺度的四分位数）；否则标记为近似并说明 | ❌ 把 GM 当中心值套 S2/S4 |
| 原文报告 **AM + SD** | 用下面 §6 的 `AM_SD → GM` 转换 | ❌ 直接用 AM 作为 GM |
| 原文报告 **Median + IQR/Range** | 用 Wan 估 `Mean`/`SD`，再转 GM | ❌ 直接把中位数当 GM（见 §6 的说明） |

**硬约束**：当 `stat_type = GM_GSD` 或 `GM_only` 时，`wan_convert.py` **必须拒绝执行**并返回 `SKIP`，理由写明"原文已在对数尺度，不得套用 Wan 公式"。

### 4.3 不可用情形清单（返回 `FAILED` / `SKIP`）

| 情形 | 返回 | 处置 |
|---|---|---|
| `stat_type ∈ {GM_GSD, GM_only}` | `SKIP` | 直接取用原值 |
| 只有中位数，无任何离散度信息 | `FAILED` | 该记录不可合并；`notes` 说明；敏感性分析中标注 |
| `q3 ≤ q1`（分位矛盾） | `FAILED` | 数据可疑，交 GATE-3 复核 |
| `max ≤ min` | `FAILED` | 同上 |
| `n` 缺失且公式需要 n（S1/S2/S4/S5/S7） | 退 `S3` 或 `S6`，并登记 `no_n_fallback` | 精度下降，须在报告中标注 |
| `η ≤ 0` / 非有限 | `FAILED` | 交人工 |
| `n < 25` | 仍计算，但打 `WARN` `small_n` | 报告标注误差风险 |
| 估算 `SD ≤ 0` | `FAILED` | 交人工 |
| 中心值 ≤ 0（对数尺度无定义） | `FAILED` | 交人工 |

## 5. 公式选择决策树

```
stat_type == GM_GSD / GM_only ?
├─ 是 → SKIP（直接取用 GM 与 GSD，不估算）
└─ 否
   ├─ 有 min 和 max（范围法）
   │   ├─ 有 n 且中心值为均值   → S1
   │   ├─ 有 n 且中心值为中位数 → S2
   │   └─ 无 n                  → S3（打 no_n_fallback）
   ├─ 有 q1 和 q3（IQR 法）
   │   ├─ 有 n 且中心值为中位数 → S4（推荐）；若数据可能偏态 → 同时算 S7 作交叉校验
   │   ├─ 有 n 且中心值为均值   → S5
   │   └─ 无 n                  → S6（打 no_n_fallback）
   └─ 都没有（仅中位数）        → FAILED
```

**出口要求**：无论走哪条路径，都必须产出 `conversion_path`，形如 `Median_IQR→Wan_S4→GM`，供 `inferred_flags` 反推（见 `unit_conversion_playbook.md` §6）。

## 6. 从 Wan 输出到 GM 的转换（本工作包特有）

Wan 公式给的是**算术尺度**的 `Mean` 与 `SD`。本工作包的目标量是 **GM**（浓度数据近似对数正态）。

### 6.1 转换公式

```
σ² = ln( 1 + (SD / Mean)² )
GM = Mean / exp(σ² / 2)
GSD = exp(σ)
```

（等价写法：`σ = sqrt(ln(1 + CV²))`，`CV = SD/Mean`）

### 6.2 直接取中位数作为 GM 的情形

若原文报告 `Median + IQR`，且**不需要**合并算术量，可以**直接把中位数作为 GM 的近似**——因为对数正态分布的中位数等于其几何均值。

| 做法 | 路径编码 | 何时用 |
|---|---|---|
| 中位数 → GM（直接） | `Median_IQR→Median_as_GM` | 数据明显对数正态；**最常用** |
| 中位数 → Wan 估 Mean/SD → GM | `Median_IQR→Wan_S4→GM` | 需要 SD/GSD 做误差线或敏感性分析 |

**两者都要登记正确的 `inferred_flags`**（`gm_from_median` 或 `gm_from_iqr`），且在敏感性分析中区分"仅直接报告 GM 子集"。

> 决策规则：**报告同时段趋势时用 `Median_as_GM`（更稳）；需要 GSD 时走 Wan 路径。** 该选择必须全项目统一，写入 `project.yaml`。
