# 敏感性分析协议（Sensitivity Analysis Protocol）

> **用途**：检验主结论对**关键方法学选择**的依赖程度。未做敏感性分析，**不得声明结论稳健**。
> **配套脚本**：`scripts/sensitivity.py`
> **教训来源**：本项目审稿意见 R1-6（尿校正方式）与 R1-7（GM 转换方式）要求补敏感性分析。

---

## 1. 为什么必须做

本工作包在 S4/S5 阶段做了多个**方法学选择**，每个选择都可能有争议：

| 选择点 | 可能的替代做法 | 影响 |
|---|---|---|
| 尿校正处理 | 只纳入肌酐校正 / 只纳入未校正 / 混合 | 影响尿砷水平 |
| GM 来源 | 仅直接报告 GM / 全部含估算 | 影响合并值 |
| 分位数→均值 | 中位数直接作 GM / 经 Wan 估算 | 影响 GM 与 GSD |
| 人群边界 | 含职业暴露 / 排除职业暴露 | 影响总体水平 |
| 队列去重 | 不去重 / 保留最大者 | 影响权重分配 |
| 量化口径 | 样本量加权 / 逆方差 | 影响权重结构 |
| 分期边界 | 方案 A / 方案 B | 影响时段数值 |

**逻辑**：如果结论在替代做法下**都成立**，则结论稳健；如果一改就变，则结论是"选择的产物"，必须如实报告。

---

## 2. 三类敏感性分析（对应本项目审稿意见）

### 2.1 分层分析（Stratified）—— 按**关键类别**分别算

**用途**：检验主形态在不同子层中是否一致。

| 分层变量 | 层 | 本项目实测规模 |
|---|---|---|
| **尿校正方式**（`adjusted`） | `Creatinine` / `SpecificGravity` / `ReferenceConversion` / `No` | 肌酐校正 177 / 比重校正 42 / 参考值换算 223 / 其余未校正 |
| **GM 来源**（`conversion_path`） | `reported_GM`（零推断） / `Wan_*` / `Median_as_GM` / `AMSD_to_LN` | — |
| **血基质**（`blood_matrix`） | `WholeBlood` / `Serum` / `Plasma` | 41 条记录（27 个研究）标题提示 serum/plasma |
| **形态**（`analyte_species`） | `Total` / `iAs` / 形态之和 | 仅 27 条提示做过形态分析 |
| **人群**（`population_group`） | `Adults` / `Minors` / `Pregnant` | — |
| **记录拆分**（`inferred_flags`） | 含 `record_split_from_study` / 不含 | — |
| **缺 n 回退**（`no_n_fallback`） | 含 / 不含 | — |

**判据**：**主形态（如"下降—回升—稳定"）在各层中是否一致**。
一致 → 写入"robust across strata"；不一致 → 如实报告差异及其来源。

**本项目结果**（R1-6）：按校正状态分为三层（肌酐 177 / 比重 42 / 参考值换算 223），"下降—回升—稳定"主形态在三层中一致 → SI Table S14a。

### 2.2 子集分析（Subset）—— 只用**最高质量**的子集

**用途**：检验结论是否依赖低质量/高推断比例的数据。

| 子集定义 | 含义 | 本项目实测 |
|---|---|---|
| **仅直接报告 GM** | `conversion_path == "reported_GM"`，零推断 | 88 条（全库 442 条） |
| **仅高质量研究** | AHRQ 得分 ≥ 9 | 125 篇 |
| **仅 n ≥ 阈值** | 排除小样本研究 | — |
| **仅同一分期方案** | 排除跨期边界记录 | — |

**本项目结果**（R1-7）：仅直接报告 GM 的 88 条子集与全部 442 条对比，主形态一致 → SI Table S14b。

**报告要求**：必须写明**子集占全库的比例**。占比过低（如 < 20%）时，即使形态一致，也只能作定性参考。

### 2.3 排除后分析（Leave-out）—— 剔除**可疑记录**后重算

**用途**：检验结论是否被少数可疑记录驱动。

| 剔除对象 | 依据 | 本项目实测 |
|---|---|---|
| 疑似职业暴露 | GATE-2 清单 | 35 个唯一研究 |
| 疑似疾病人群 | GATE-2 清单 | 55 个唯一研究 |
| 血基质存疑（serum/plasma） | `flag_blood_matrix` | 41 条 / 27 个研究 |
| **单记录权重主导层** | `max_weight_share > 30%` | S5 的 `note` 列标出 |
| `FAILED` 记录 | S4 清单 | — |
| 低质量研究 | AHRQ ≤ 4 | 12 篇 |

**判据**：剔除后主结论**方向与量级**是否改变。
改变 → 必须改写叙述；不改变 → 写入"robust to exclusion of ..."。

**留一法（leave-one-out）可选**：逐条剔除单条记录重算，观察结论波动。记录数多时只对"权重占比最高"的前 N 条执行。

## 3. 判定标准

| 结果 | 判定 | 正文写法 |
|---|---|---|
| 各方案下结论方向与量级均一致 | **稳健** | "consistent across sensitivity analyses" |
| 方向一致但量级有差异（> 20%） | **部分稳健** | 说明差异范围与成因 |
| 方向改变 | **不稳健** | ★ 必须改写结论，或限定结论范围 |

**禁止**：只报告"一致"的情形而隐去不一致的情形（选择性报告）。

---

## 4. 强制性要求

| # | 要求 |
|---|---|
| 1 | **每个由 AI/脚本做出的关键选择，都要有对应敏感性分析**（或说明为何不需要） |
| 2 | 敏感性结果的**样本量/记录数必须报告**（子集过小则结论降级） |
| 3 | 主形态一致性的判定必须**逐时段列数值**，不能只说"一致" |
| 4 | 不一致的层必须**在正文或局限中明确说明**，不得只放补充材料 |
| 5 | 敏感性分析的产出必须**带快照指纹**，且与主分析**同一快照** |
| 6 | 方法学部分必须列出**所有执行过的敏感性分析**及其实验设计 |

---

## 5. 输出格式

`04_敏感性分析报告.md` + 结果表：

| 列 | 内容 |
|---|---|
| `analysis_id` | S1/S2/… 编号 |
| `type` | stratified / subset / leave_out |
| `definition` | 层或子集的定义（可复现） |
| `period` | 时段 |
| `n_records` | 记录数 |
| `n_studies` | 研究数 |
| `GM` / `GSD` | 该层该时段的加权值 |
| `pattern` | 形态标签（如"下降—回升—稳定"） |
| `consistent_with_main` | 是 / 否 |

**附加**：`pattern_consistency_matrix.csv`（层 × 时段 × 形态）便于人快速判读。

## 6. 与 GATE-5 的关系

| 项 | 内容 |
|---|---|
| 所属闸门 | **GATE-5（去重与敏感性裁决）** |
| AI 产出 | 三套分析结果 + 主形态一致性判定 + 样本量统计 |
| 人工裁决 | ① 哪些子集因样本量不足而**不得**用于结论；② 若排除后主结论改变，如何改写正文；③ 是否批准"稳健性"声明 |

**硬规则**：**AI 不得自行声明"结论稳健"**，只能给出"各层形态一致/不一致"的事实与数值。

---

## 7. 纪律（六条）

| # | 纪律 |
|---|---|
| 1 | **敏感性分析未做，不得声明稳健** |
| 2 | **判定必须基于逐时段数值**，不凭印象 |
| 3 | **子集必须报告占全库比例** |
| 4 | **不一致必须报告**，不得选择性呈现 |
| 5 | **敏感性结果与主分析必须同快照**，否则无意义 |
| 6 | **AI 给事实，人给结论** |
