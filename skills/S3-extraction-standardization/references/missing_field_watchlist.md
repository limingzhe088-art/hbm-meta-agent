# AI 易漏字段黑名单与可疑值模式（Missing-Field Watchlist）

> 用途：S3 阶段的两个清单。**清单 A** 是"AI 一定会漏的字段"，校对时优先查；**清单 B** 是"看起来不对的值"，用于自动扫描与人工判断。
> 本文件内容来自一个真实项目的实证（384 篇文献 / 688 条记录），不是推测。

---

## 清单 A：AI 易漏字段黑名单（按漏提频率降序）

| 排序 | 字段 | 漏提表现 | 为什么必查 | 校对动作 |
|---|---|---|---|---|
| **1** | `sample_size` | 亚组行填总样本量，或整列空 | 决定权重，错则全部加权结果错 | 逐行确认"该行对应多少个受试者" |
| **2** | `time` | 填发表年份；或空缺 | 决定分期与趋势 | 与 `t_publication` 对比，差值 <1 年时回原文确认 |
| **3** | `adjusted` | 尿样几乎不被主动填写 | 决定单位口径 | 看 `unit_original` 是否含 `/g Cr` 反推 |
| **4** | `blood_matrix` | 血样基质沉默 | 全血/血清浓度差异大 | 搜标题与摘要中 serum / plasma / 血清 / 血浆 |
| **5** | `stat_type` | 不填，或与实际列不符 | 决定 S4 换算路径 | 看哪些 `initial_*` 列有值，反推类型 |
| **6** | `unit_original` | 被"规范化"成统一写法 | 单位换算依据丢失 | 要求原样抄录；检查是否有 `μg`→`ug` 被改写 |
| **7** | `population_group` | 留空或全填 `Unknown` | 决定生理参数与 EDI | 按年龄/人群原文归类 |
| **8** | `city` / `province` | 多个市用逗号连写 | 空间分析与聚类失败 | 改为单值或 `\|` 分隔 |
| **9** | `analyte_species` | 不区分总砷与形态砷 | 影响可比性声明 | 实证：仅少数研究提示做过形态分析 |
| **10** | `qc_reported` | 不填 | 影响质量评分 | 查是否提到 SRM/回收率/精密度 |
| **11** | `initial_gsd` | 与 `initial_sd` 混填 | 误差线错误 | 区分几何 SD 与算术 SD |
| **12** | `gender` / `male_n` / `female_n` | 分性别数据未拆行 | 分层结果缺失 | 分性别报告必须拆行 |
| **13** | `detection_method` | 只写"检测了" | 影响质量评分与可比性 | 要求具体方法名 |
| **14** | 附件内容 | 静默跳过 Supplementary | 漏掉大量数据 | 强制"先告知支撑材料内容" |
| **15** | `notes` | 一片空白 | 后人无法追溯疑问 | 强制填写不确定项 |

### 实证统计（可作校对工作量预估）

| 项目 | 实测值 |
|---|---|
| 总记录数 | 688 条 |
| 尿 / 血 / 脐血记录 | 442 / 204 / 42 条 |
| 血样中标题提示 serum/plasma 的记录 | **41 条（27 个唯一研究）** → 全部需人工确认基质 |
| 提示做过砷形态分析的记录 | 27 条（其余为总砷） |
| 采样时间齐全率 | 100%（该项目做到了；缺失时不得用于趋势分析） |
| 尿样校正状态分布 | 肌酐校正 177 / 比重校正 42 / 参考值换算 223（其余未校正） |

> **推论**：血基质与尿校正状态这两项，AI 漏提率接近 100%，必须靠专项扫描（`scripts/`）而非依赖提示词。

## 清单 B：可疑值模式（自动扫描 + 人工判断）

### B1. 单位与量级类

| 模式 | 判据 | 可能原因 | 处理 |
|---|---|---|---|
| 量级差 10³ 倍 | 尿砷 > 1000 或 < 0.1（`μg/g Cr` 语境） | 单位是 `μg/L` 却当 `μg/g Cr`，或 mg/μg 混淆 | 回原文核对 `unit_original` |
| 血砷量级异常 | 血砷 > 50 `μg/L` | 急性中毒病例、职业人群、或单位错 | 查是否病例组；**不可直接合并** |
| 换算前后同值 | `initial_*` 与 `conversion` 后完全相同，但路径写了"换算" | 换算逻辑未生效 | 检查 `conversion_path` |
| 单位字符混用 | 同表内出现 `μg/L` 与 `ug/L` 与 `µg/L` | 抄录不一致 | 正常，S4 会统一；但需确认不是两种单位 |

### B2. 统计量关系类

| 模式 | 判据 | 含义 | 处理 |
|---|---|---|---|
| `GM > AM` 且差异 > 50% | 对数正态分布下 GM 通常 < AM | 提取错位（把 P75 当 GM 等） | 逐条核对 |
| `GM == AM`（严格相等） | 除非原文如此报告 | 可能把 AM 填进 GM 列 | 核对 |
| `P25 > 中位数` 或 `P75 < 中位数` | 逻辑矛盾 | 行列错位 | 修正 |
| `min > max` | 逻辑矛盾 | 行列错位 | 修正 |
| `GSD < 1.0` | 几何 SD 不可能 < 1 | 填成了算术 SD，或填了 CV | 核对 |
| `GM < min` 或 `GM > max` | 逻辑矛盾 | 错位 | 修正 |

### B3. 样本量类

| 模式 | 判据 | 含义 | 处理 |
|---|---|---|---|
| 亚组样本量之和 > 总样本量 | 分组交叉 | 通常正常（分性别×分年龄会有交叉） | 记 `notes`，去重策略交 GATE-5 |
| 同 `study_no` 多行样本量完全相同 | 疑似总样本量被复制 | 权重被系统性放大 | **逐行回原文确认** |
| `sample_size` 为 0 或空 | 不可加权 | 该行不可合并 | 留空 + `notes` |
| 样本量 > 千万 | 异常 | 可能填了人年数或其他指标 | 核对 |

### B4. 时间类

| 模式 | 判据 | 含义 | 处理 |
|---|---|---|---|
| `time == t_publication` | 抽样异常 | 可能误填发表年 | **逐条回原文确认**（本项目最高频错误） |
| `time < 1900` 或 `> 当前年+1` | 越界 | 录入错误 | 修正 |
| `time_start > time_end` | 逻辑矛盾 | 行列错位 | 修正 |

### B5. 人群边界类（→ 直接进 GATE-2 疑似清单）

| 模式 | 扫描方式 | 产出 |
|---|---|---|
| 疑似职业暴露 | 标题含职业关键词且无 `non-occupational` 否定词 | 疑似清单，人工逐条裁决 |
| 疑似疾病人群 | 标题含疾病/病例对照关键词 | 同上 |
| 疑似血基质 | 标题含 `serum`/`plasma`/`血清`/`血浆` | 打 `flag_blood_matrix` |
| 同队列重复 | 同城市 + 同基质 + 同作者 聚簇 ≥4 篇 | 队列聚簇清单 |
