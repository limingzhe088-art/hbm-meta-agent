# EDI 暴露评估参数与公式（Estimated Daily Intake）

> **用途**：S5 把生物标志物浓度反推为估计每日摄入量（EDI）。
> **保真声明**：公式与参数与原项目 R 脚本（`EDI计算_run.R` / `EDI计算_modified.R`）**完全一致，只改语言不改算法**。
> **⚠️ 关键**：血路 EDI 曾存在**单位错误**并被审稿人指出（R1-1）。本文件明确标注**修正后公式**与**已证伪的旧公式**。

---

## 1. EDI 的意义与局限

**意义**：把不同基质、不同单位的生物标志物浓度，换算为可跨基质比较的"每日摄入量"（`μg/kg bw/day`），使"尿砷趋势"与"血砷趋势"能在同一量纲上对话。

**局限（必须写入方法学与讨论）**：

| 局限 | 说明 |
|---|---|
| 参数是**人群均值假设**，非个体测量 | 体重、尿量、肌酐排泄均取参考值 |
| 吸收率 `ABS=0.7` 是**假设值** | 必须附敏感性说明 |
| 血路动力学参数不确定 | 血砷反映短期暴露 → **仅作探索性重建** |
| 只适用于经口暴露路径 | 吸入/皮肤暴露不适用 |
| `Mixed` / `Unknown` 人群**无法计算** | 生理参数无法确定 → 跳过 |

## 2. 尿路 EDI（双路径，交叉验证）

### 2.1 路径 A：肌酐排泄法（`creatinine_excretion`，主口径）

```
EDI_urine = GM × CE / (BW × ABS)
```

| 符号 | 含义 | 单位 |
|---|---|---|
| `GM` | 尿砷肌酐校正浓度（`gm_summary`） | μg/g Cr |
| `CE` | 每日肌酐排泄量 | g/day |
| `BW` | 体重 | kg |
| `ABS` | 经口吸收比例 | 无量纲 |
| 输出 | `EDI_urine` | μg/kg bw/day |

### 2.2 路径 B：尿量法（`urine_volume`，交叉验证）

```
尿浓度(μg/L) = GM × CC_creat
EDI_urine    = 尿浓度 × V / (BW × ABS)
```

| 符号 | 含义 | 单位 |
|---|---|---|
| `CC_creat` | 参考肌酐浓度 | g/L |
| `V` | 每日尿量 | L/day |

### 2.3 两条路径为何并存

因 `CC = CE / V`（见 `S4/references/icrp89_urine_reference.md`），两式在参数自洽时**数学等价**：

```
路径A：GM × CE / (BW × ABS)
路径B：GM × CC × V / (BW × ABS) = GM × (CE/V) × V / (BW × ABS) = GM × CE / (BW × ABS)
```

**并存的目的**：**交叉验证参数表自洽性**。若两条路径结果不一致，说明该人群档的 `CC` 与 `CE/V` 不自洽（如 `Minors` 档）。

| 情形 | 相对差 | 处理 |
|---|---|---|
| < 0.5% | 正常（舍入差异） | 正常报告 |
| 0.5%–3% | 参数表有轻微舍入 | 报告并在 `conversion_params` 标注 |
| **> 3%** | **参数不自洽** | ★ 报 `WARN inconsistent_param`，进敏感性分层，写入局限 |

**本项目已知**：`Minors` 档 `CC=0.815` vs `CE/V=0.881`，相对差约 **8%** → 必须标注。

### 2.4 主口径与报告

- **主口径**：`creatinine_excretion`（路径 A），用于主要结果
- **路径 B** 作为验证与敏感性分析，结果写入补充材料
- 方法学中说明为何选 A 为主（本项目：`CE` 是 ICRP 直接给出的原值，`CC` 是派生值）

## 3. 血路 EDI（★ 修正后公式）

### 3.1 修正后公式（现行）

```
EDI_blood = (BAs × Vd) / (ABS × τ)
```

| 符号 | 值/单位 | 说明 |
|---|---|---|
| `BAs` | μg/L | 血砷浓度（`gm_summary`） |
| `Vd` | **2.0 L/kg** | 表观分布容积，**已按体重标准化** |
| `ABS` | 0.7 | 经口吸收比例 |
| `τ` | **1.0 day** | 平均滞留时间 |
| 输出 | μg/kg bw/day | |

**关键点**：`Vd` 已按体重标准化为 `L/kg`，因此**不再除以 `BW`**。

### 3.2 ❌ 已证伪的旧公式（严禁使用）

```
EDI_blood = (BAs × Vd) / (BW × ABS × τ)     ← 单位错误
```

**错在哪**：`Vd` 单位已是 `L/kg`，再除以 `BW`（kg）会使量纲变成 `μg·L/(kg²·day)`，与目标单位 `μg/kg/day` 不符；数值上会把结果**系统性缩小约 60 倍**（BW=60 时）。

**本项目实证**：该错误被审稿人指出（R1-1），修正后血砷 EDI 中位数由错误值变为 `6.54 / 5.11 / 3.36`（2001-2010 / 2011-2020 / 2021-2024）。旧版脚本 `EDI计算_modified.R` 保留了错误公式，`EDI计算_run.R` 为修正版——**本工作包只实现修正版**，并在自检中断言旧公式不再被使用。

### 3.3 ★ 脐带血：不计算 EDI（方案 A）

**脐血反映胎儿内暴露，成人血路参数在模型层面不适用。**

| 项 | 内容 |
|---|---|
| 决策 | 脐血记录**跳过 EDI 并计数**（不套用成人参数） |
| 状态 | `SKIP` |
| 标记 | `cordblood_edi_skipped` |
| 参数留痕 | `route=cordblood;edi_not_computed;reason=fetal_parameters_unavailable` |
| 计数要求 | 必须进入结果表计数与局限说明 |

**为什么不"用成人值近似 + 标注"**：成人的 `Vd`（表观分布容积）、`τ`（平均滞留时间）与 `ABS`（经口吸收比例）对胎儿是**模型对象错配**，而非参数精度不足。产出的数字看似合理却无依据；一旦审稿人追问参数出处，无正当来源可答。**用错误模型的数字加免责声明，不如不报数字。**

**可选扩展（方案 B）**：若使用者能提供经过审定的胎儿/新生儿药代动力学参数（`Vd`、`τ`、经胎盘转运模型、适用胎龄范围、不确定性），可通过 `project.yaml → edi.cordblood_route` 接入，参数化实现、不硬编码。在此之前默认方案 A。

### 3.4 必须标注"探索性重建"血砷反映**短期**暴露（数天至数周），且 `Vd`、`τ` 是不确定参数。因此：

- 结果表与图必须标注：**"exploratory reconstruction"** / **"探索性重建"**
- 讨论部分必须说明：血路 EDI **不应**与尿路 EDI 直接比较量级
- 方法学必须写明：`Vd`、`τ` 的取值来源与不确定性

**本项目实证**：血路 EDI 显著高于尿路 EDI（6.54 vs 2.13 量级），这不是暴露差异，而是**参数不确定性的体现**。手稿已明确说明这一点。

## 4. 参数表

### 4.1 ICRP 89 派生参数（与原 R 脚本一致）

| `population_group` | `CE` (g/day) | `V` (L/day) | `CC_creat` (g/L) | `BW` (kg) | 来源 |
|---|---|---|---|---|---|
| `Adults` | 1.35 | 1.4 | 0.964 | 60 | ICRP 89, ≥18 不分性别 |
| `Pregnant` | 1.275 | 2.0 | 0.638 | 60 | NHANES |
| `Minors` | 0.925 | 1.05 | 0.815 | 20 | ICRP 89, 10–15 区间 |
| `Elderly` | 1.35 | 1.4 | 0.964 | 60 | 同成人（打 `coarse_age`） |
| `Mixed` | — | — | — | — | ★ **不计算**（参数无法确定） |
| `Unknown` | — | — | — | — | ★ **不计算** |

### 4.2 通用参数

| 参数 | 值 | 说明 |
|---|---|---|
| `ABS` | **0.7** | 假设的可溶性无机砷经口吸收比例 |
| `Vd` | **2.0 L/kg** | 表观分布容积（血路） |
| `τ` | **1.0 day** | 平均滞留时间（血路） |

### 4.3 `ABS` 的敏感性要求

`ABS=0.7` 是**假设值**，不是测量值。因为 `EDI ∝ 1/ABS`，必须：

- 在方法学中明确定义为"假设的经口吸收比例"（**不得**写成"文献值"）
- 在局限部分给出敏感性说明：`ABS` 取 0.5–1.0 时 EDI 的变化范围
- 本项目实证：审稿人 R1-2 正是要求补这一点

## 5. 汇总统计口径

### 5.1 按分层单元输出

| 统计量 | 计算方式 | 说明 |
|---|---|---|
| `EDI_GM` | 加权几何均值（同 `weighted_gm.py`） | 主口径 |
| `EDI_GSD` | 加权几何标准差 | 误差线 |
| `EDI_median` | **未加权**中位数 | 保留原 R 行为 |
| `EDI_P05/P25/P50/P75/P95` | **加权**分位数（`wtd.quantile` 等价） | R 的 `Hmisc::wtd.quantile` |
| `n_studies` | 记录数 | |
| `total_sample` | 样本量和 | **记录级求和**（须标注） |

**权重为整数样本量**时，累积权重法与 R 的 `wtd.quantile` 结果一致。

### 5.2 `Mixed` / `Unknown` 的处理

`population_group ∈ {Mixed, Unknown}` 的记录：
- **跳过 EDI 计算**
- 但在结果表中**计数并报告**（"X 条记录因人群类别不明而未计算 EDI"）
- 不得静默丢弃

## 7. 与原 R 实现的对应关系

| R（原项目） | Python（本工作包） | 说明 |
|---|---|---|
| `(gm_value * p$CE) / (p$BW * p$ABS)` | `gm * CE / (BW * ABS)` | 路径 A，逐项对应 |
| `(urine_conc * p$V) / (p$BW * p$ABS)`，`urine_conc = gm * CC` | `gm * CC * V / (BW * ABS)` | 路径 B |
| `(blood_as * Vd) / (ABS * tau)`（修正版） | `BAs * Vd / (ABS * tau)` | ★ 修正公式 |
| ~~`(blood_as * Vd) / (BW * ABS * tau)`~~ | **不实现** | ❌ 已证伪 |
| `wtd.quantile(EDI, weights = Sample_Size, probs = ...)` | 累积权重分位数 | 整数权重时一致 |
| `median(EDI, na.rm = TRUE)` | 未加权中位数 | 保留原行为 |
| `grepl("Adults\|Elderly\|成人", Population)` | 映射到 `population_group` 枚举 | 归类改由 S3 完成 |
