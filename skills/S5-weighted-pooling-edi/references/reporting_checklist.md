# 结果报告检查清单（Reporting Checklist）

> **用途**：S5 产出结果前的强制自检。**未通过任一项不得出图/出表/进入 S6。**
> **教训来源**：本项目三条审稿意见（R2-2 时段数值过时、R2-3 地区排序不一致、R3-2 参与者重复计数）都源于报告环节缺少强制检查。

---

## 1. 记录数 vs 唯一参与者（★ 最高频问题）

| # | 检查项 | 通过判据 |
|---|---|---|
| 1.1 | 每个结果表/图是否都标注了 `n` **的类型**？ | 明确写出是 `record_count`、`study_count` 还是 `participants` |
| 1.2 | 参与者总数是否避免了"唯一个体"的暗示？ | 记录级求和用 `participant records` / `record-level sums` |
| 1.3 | 是否有队列去重说明？ | 要么说明已去重及方法，要么说明"未去重，为记录级求和" |
| 1.4 | 图注/表注是否含固定免责文案？ | 例："Sample sizes are record-level sums; some participants contributed to more than one record or matrix." |
| 1.5 | 同一人的多基质记录（尿+血）是否被说明？ | 已说明 |

**禁止措辞**：`participants`、`individuals`、`subjects`（在未去重语境下）。

---

## 2. 数值可追溯性

| # | 检查项 | 通过判据 |
|---|---|---|
| 2.1 | 每个报告数字能否追溯到"快照某一行 + 配置某一条"？ | 无孤儿数字 |
| 2.2 | 是否携带快照指纹？ | 结果表含 `sha256` + `generated_at` + `config_version` |
| 2.3 | 分期标签是否全部来自 `period_scheme`？ | 无手工写的年份区间 |
| 2.4 | 地区排序是否由脚本重新生成？ | 非手工维护 |
| 2.5 | 权重占比是否已诊断？ | `max_weight_share` 已输出 |

---

## 3. 加权合并的正确性

| # | 检查项 | 通过判据 |
|---|---|---|
| 3.1 | `GM_w` 是否落在输入记录的 `[min, max]` 区间内？ | 是（对数加权均值不可能超出输入范围） |
| 3.2 | `GSD_w ≥ 1`？ | 是 |
| 3.3 | 权重之和 > 0，无零/负权重？ | 是 |
| 3.4 | 单记录权重占比 > 30% 时是否做了敏感性分析？ | 已做或已说明 |
| 3.5 | 分层单元记录数 < 3 的是否已标注？ | 已标注 |
| 3.6 | 无数据时段是否在图注中说明（而非画成 0）？ | 已说明 |
| 3.7 | 对数底数是否与 `project.yaml` 声明一致？ | 一致 |

---

## 4. 误差线与区间

| # | 检查项 | 通过判据 |
|---|---|---|
| 4.1 | 误差线定义是否写入图注？ | 明确写"±1 log unit (GM/GSD ~ GM×GSD)"或"95% CI" |
| 4.2 | 是否区分了"记录间变异"与"抽样误差"？ | 已区分并说明 |
| 4.3 | GSD 是否被误标为 95% CI？ | 无此误标 |

---

## 5. 分层维度的完整性

| # | 检查项 | 通过判据 |
|---|---|---|
| 5.1 | 不同基质是否**绝不合并**？ | 尿/血/脐血各自独立 |
| 5.2 | `Serum`/`Plasma` 是否与 `WholeBlood` 分层？ | 已分层或已说明合并依据 |
| 5.3 | `analyte_species` 不同的是否分层？ | 已分层 |
| 5.4 | 尿校正方式是否作为敏感性分层？ | 已做 |
| 5.5 | `Mixed`/`Unknown` 人群是否在 EDI 中跳过并计数？ | 已计数 |

---

## 6. EDI 专项

| # | 检查项 | 通过判据 |
|---|---|---|
| 6.1 | 血路 EDI 是否用了**修正后公式** `(BAs×Vd)/(ABS×τ)`？ | 是 |
| 6.2 | 血路 EDI 是否标注 `exploratory reconstruction`？ | 已标注 |
| 6.3 | 是否**避免**将血路与尿路 EDI 直接比较量级？ | 未直接比较，或已说明不可比 |
| 6.4 | `ABS=0.7` 是否定义为"假设值"（非"文献值"）？ | 已定义 |
| 6.5 | `ABS` 是否附敏感性说明？ | 已附（如 0.5–1.0 范围） |
| 6.6 | 尿路双路径结果是否已交叉验证？ | 相对差已计算；> 3% 已报警 |
| 6.7 | 参数表不自洽项（如 `Minors`）是否已标注？ | 已标注 |
| 6.8 | `Vd`、`τ` 取值来源与不确定性是否写入方法学？ | 已写 |

---

## 7. 图注/表注的必备要素

每张图与每张表必须包含：

| # | 要素 |
|---|---|
| 7.1 | 单位（`ug/g Cr` / `ug/L` / `μg/kg bw/day`） |
| 7.2 | `n` 的类型与数量（记录数 / 研究数 / 参与者） |
| 7.3 | 误差线或离散度的定义 |
| 7.4 | 加权口径（"sample-size-weighted"） |
| 7.5 | 无数据的时期/地区说明 |
| 7.6 | 分层的具体定义（如"by urine-correction status"） |
| 7.7 | EDI 图的探索性标注（若适用） |
| 7.8 | 快照标识（至少在图注末或补充材料中） |

---

## 8. 需写入局限说明的事项

以下事项若存在，**必须**出现在稿件局限部分：

- [ ] 记录级求和 ≠ 唯一参与者；同一队列可能被多次报告
- [ ] 未做队列去重的说明（或已做，说明方法与影响）
- [ ] `ABS` 是假设值
- [ ] 血路 EDI 是探索性重建
- [ ] `Mixed`/`Unknown` 人群未计算 EDI 的条数
- [ ] 参数表不自洽人群档（如 `Minors`）的影响
- [ ] Wan 公式估算而来的记录占比（S4 提供）
- [ ] `FAILED` 记录被排除的条数与原因（S4 提供）
- [ ] 分层单元样本量不足的结论限制
- [ ] 文献覆盖 ≠ 全国代表性（早期研究集中于高暴露区）
