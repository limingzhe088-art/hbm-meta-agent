## 3. 待人工提供信息或决策（⬜ `NEEDS_HUMAN`）

> AI 不得代答此类事项。每项须写明"谁来完成"。

| 编号 | 事项 | 归属类型 | 谁来完成 | 状态 |
|---|---|---|---|---|
| | 基金信息 / 项目编号 | 外部信息 | 作者 | ⬜ |
| | 是否预先注册（PROSPERO 等）及注册号 | 事实性声明 | 作者 | ⬜ |
| | 推荐审稿人 | 外部信息 | 通讯作者 | ⬜ |
| | CRediT 作者贡献分工 | 声明 | 全体作者 | ⬜ |
| | AI 使用声明措辞 | 声明 | 作者 | ⬜ |
| | 需从原文补标的数据（形态/血基质等） | 领域判断 | 研究者 | ⬜ |
| | 需裁决的排除名单 | 领域判断 | 研究者 | ⬜ |
| | 单位英文名 / 作者英文名拼写 | 事实 | 作者 | ⬜ |

> ⚠️ **凭证类信息**（账号密码等）**不得**写入本文件或任何交付物。若发现残留，立即删除并轮换凭证。
