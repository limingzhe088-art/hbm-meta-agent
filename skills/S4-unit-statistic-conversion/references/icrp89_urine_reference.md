# ICRP 89 尿量/肌酐参考值 —— 参数选择规则

> **来源**：ICRP Publication 89, *Basic Anatomical and Physiological Data for Use in Radiological Protection: Reference Values* (2002)，以及项目参考的 NHANES 孕妇尿肌酐数据。
> **用途**：S4 阶段把"体积浓度（μg/L）"的尿样数据换算为"肌酐校正浓度（μg/g Cr）"。
> **保真声明**：本文件参数表与原项目使用的 R 脚本（`EDI计算_run.R` / `描述性分析_run.R`）及 `10_参考附件/一般人群尿比重、肌酐值.docx` 完全一致。

---

## 1. 为什么必须校正尿样

尿液中物质浓度受**饮水与稀释状态**强烈影响：同一个人饮水多时尿砷可能只有晨尿的几分之一。若把不同研究、不同采样时点的 μg/L 直接合并，引入的是**与暴露无关的噪音**，且噪音量级可能大于研究间真实差异。

**校正路径**：体积浓度 → 除以该人群的肌酐浓度 → 得到 `μg/g Cr`。

```
浓度(μg/g Cr) = 浓度(μg/L) ÷ 肌酐浓度(g/L)
```

等价写法（用排泄量）：
```
浓度(μg/g Cr) = 浓度(μg/L) × 每日尿量(L/day) ÷ 每日肌酐排泄量(g/day)
```

**两条路径必须自洽**：`肌酐浓度(g/L) = 每日肌酐排泄量(g/day) ÷ 每日尿量(L/day)`。

## 2. 参数表（ICRP 89 派生）

| 人群 | 年龄 | 性别 | 每日肌酐排泄量 `CE` (g/day) | 每日尿量 `V` (L/day) | 肌酐浓度 `CC` (g/L) | 校验 |
|---|---|---|---|---|---|---|
| New born | 0 | — | 0.05 | 0.3 | 0.167 | 0.05/0.3 = 0.167 ✅ |
| 婴儿 | 1 | — | 0.11 | 0.4 | 0.275 | 0.11/0.4 = 0.275 ✅ |
| 幼儿 | 5 | — | 0.33 | 0.5 | 0.66 | 0.33/0.5 = 0.66 ✅ |
| 儿童 | 10 | — | 0.65 | 0.7 | 0.929 | 0.65/0.7 = 0.929 ✅ |
| 青少年 | 15 | — | 1.2 | 1.4 | 0.857 | 1.2/1.4 = 0.857 ✅ |
| 成人 | 15 | 男 | 1.4 | 1.6 | 0.875 | 1.4/1.6 = 0.875 ✅ |
| 成人 | 15 | 女 | 1.0 | 1.2 | 0.833 | 1.0/1.2 = 0.833 ✅ |
| 未分性别 | 10–15 | — | 0.925 | 1.05 | 0.815 | 0.925/1.05 = 0.881 ⚠️ 见 §4 注 |
| 成人 | ≥18 | — | 1.35 | 1.4 | 0.964 | 1.35/1.4 = 0.964 ✅ |
| 成人 | ≥18 | 男 | 1.7 | 1.6 | 1.063 | 1.7/1.6 = 1.063 ✅ |
| 成人 | ≥18 | 女 | 1.0 | 1.2 | 0.833 | 1.0/1.2 = 0.833 ✅ |
| **孕妇** | — | — | **1.275** | **2.0** | **0.638** | 1.275/2.0 = 0.638 ✅（NHANES 来源） |

**本工作包默认采用的三档**（与原项目 R 脚本一致，供 `project.yaml → urine_reference` 使用）：

| `population_group` | `CE` (g/day) | `V` (L/day) | `CC_creat` (g/L) | 来源 |
|---|---|---|---|---|
| `Adults` | 1.35 | 1.4 | 0.964 | ICRP 89, ≥18 不分性别 |
| `Pregnant` | 1.275 | 2.0 | 0.638 | NHANES |
| `Minors` | 0.925 | 1.05 | 0.815 | ICRP 89, 10–15 区间 |

> ⚠️ `Minors` 行的 `CC` 与 `CE/V` 不自洽（0.815 ≠ 0.881）。这是**原项目沿用的取值**，本工作包**原样保留**以保证算法保真，但要求：
> ① 换算时必须记录用的是**哪一路径**（`CC` 直除 还是 `CE/V` 等价式）；
> ② 该不自洽项写入 `conversion_params` 供审计；
> ③ 敏感性分析中把 `Minors` 记录单列一层。

## 3. 参数选择规则（决策树）

```
1) 是否孕妇 / 哺乳期？
   ├─ 是 → Pregnant：CE=1.275, V=2.0, CC=0.638
   └─ 否 → 2)

2) 年龄已知？
   ├─ 新生儿（0）        → New born：CC=0.167
   ├─ 婴儿（~1）         → 婴儿：CC=0.275
   ├─ 幼儿（~5）         → 幼儿：CC=0.66
   ├─ 儿童（~10）        → 儿童：CC=0.929
   ├─ 青少年（~15）      → 青少年：CC=0.857
   ├─ 成人（≥18）        → 3)
   └─ 年龄未知但人群为儿童/青少年 → Minors：CC=0.815（打 WARN `coarse_age`）

3) 性别已知？
   ├─ 男 → 成人男：CE=1.7, V=1.6, CC=1.063
   ├─ 女 → 成人女：CE=1.0, V=1.2, CC=0.833
   └─ 未知/未分性别 → 成人通用：CE=1.35, V=1.4, CC=0.964  ← 默认
```

**优先级**：`孕妇` > `年龄段` > `性别`。即孕妇身份覆盖年龄与性别；有具体年龄时不使用 `Minors` 的粗值。

## 4. 参数选择注意事项

| # | 注意事项 | 处理 |
|---|---|---|
| 1 | **性别不明的成人用通用值**（`CC=0.964`），不得默认男性 | 默认男性会把尿砷浓度系统性低估约 10% |
| 2 | **孕期的肌酐排泄随孕周变化** | 用 NHANES 均值 `CC=0.638`；差异写入局限说明，并做敏感性分析 |
| 3 | **儿童参数随年龄跨度大**（0.275 → 0.929） | 原文只写"儿童"时用 `Minors` 粗值并打 `coarse_age` |
| 4 | **同表内不得混用路径** | 要么全用 `CC` 直除，要么全用 `CE/V` 等价式；混用会产生不自洽 |
| 5 | 若原文**已给 `μg/g Cr`** | 不换算，`adjusted = Creatinine`，`conversion_path = reported_creatinine_corrected` |
| 6 | 若原文**用比重校正** | `adjusted = SpecificGravity`，**单独分层**，不套用 ICRP |
| 7 | 若原文**未校正** | `adjusted = No`；可换算（用 ICRP）或保留为 μg/L；**选择必须全项目统一** |
| 8 | **不得对血样使用本表** | 本表仅适用于尿样；血/脐血直接使用 μg/L |

## 5. 换算路径编码（供 `inferred_flags` 反推）

| 场景 | `conversion_path` | 自动登记的 `inferred_flags` |
|---|---|---|
| 原文已肌酐校正 | `reported_creatinine_corrected` | （无） |
| μg/L → μg/g Cr，用 CC 直除 | `ug/L→ICRP89_{group}→ug/g Cr` | `unit_converted_creatinine` |
| μg/L → μg/g Cr，用 CE/V 等价式 | `ug/L→ICRP89_{group}_CEV→ug/g Cr` | `unit_converted_creatinine` |
| μg/g Cr → μg/L（反向） | `ug/g Cr→ICRP89_{group}→ug/L` | `unit_converted_volume` |
| 比重校正（不换算） | `specific_gravity_reported` | （无，但进分层） |
| 未校正（不换算） | `uncorrected_kept` | （无，但进分层） |

其中 `{group}` ∈ `Adults` / `Pregnant` / `Minors` / `Adult_Male` / `Adult_Female` / `Newborn` / `Infant` / `Toddler` / `Child` / `Adolescent`。

## 6. 完整留痕要求

每次换算必须记录（写入 `conversion_params`）：

```
group=Adults;CE=1.35;V=1.4;CC=0.964;path=CC_direct;source=ICRP89
```

| 键 | 含义 |
|---|---|
| `group` | 选用的人群档 |
| `CE` / `V` / `CC` | 实际使用的参数值 |
| `path` | `CC_direct`（直除肌酐浓度）或 `CEV_equivalent`（等价式）或 `reported`（原文已校正） |
| `source` | `ICRP89` / `NHANES` / `reported` |

**审计用途**：S6 的数值审计可比对"同一记录在两次运行中是否用了同一 `group`"，从而发现口径漂移。
