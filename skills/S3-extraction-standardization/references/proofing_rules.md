# 校对规则（Proofing Rules）

> 用途：GATE-3 人工逐条校对的操作手册。**AI 初提 → 人工逐条核对 → 标记 `verified` → 主表冻结。**
> 核心原则：**AI 负责提速，人负责真实性。未经逐条校对的记录不得用于主结论。**

---

## 1. 为什么校对不可省（实证）

在一个真实项目中（384 篇文献、688 条记录），AI 初提后的校对环节发现：

- **`time` 字段最常出错**：AI 倾向填发表年份；这同时污染"时间趋势"与"分期结果"，且事后极难发现。
- **条件必填字段最常缺失**：尿样的校正状态（`adjusted`）、血样的基质（`blood_matrix`）几乎不被 AI 主动填写。
- **样本量污染**：AI 常把全文总样本量填进每个亚组行，导致权重被系统性放大。
- **统计量错位**：把中位数填进均值列，把 P25–P75 当范围填。
- **静默跳过附件**：不报告 Supplementary 中存在的补充数据。

因此校对不是"抽查"，而是**逐条**。

---

## 2. 校对的操作顺序（按优先级，从上到下）

> 顺序依据"错误造成的下游污染范围"排序——先修影响面最大的。

| 优先级 | 检查项 | 为什么排这个位置 |
|---|---|---|
| **P1** | `sample_size` 是否为**该行**对应样本量 | 决定权重。错则所有加权结果错，且无法事后察觉 |
| **P2** | `time` 是否为**采样/招募年份**（非发表年） | 决定分期与趋势。错则整个时间分析错 |
| **P3** | `sample_type` + `blood_matrix` + `adjusted` | 决定单位口径与能否合并。错则把不可比数据混池 |
| **P4** | `stat_type` 与各 `initial_*` 列是否对位 | 决定换算路径。错则 GM 估算错 |
| **P5** | `unit_original` 是否**原样**抄录 | 决定单位换算。错则量级差 1000 倍 |
| **P6** | `population_group` / `gender` / 亚组拆行 | 决定分层结果 |
| **P7** | 时空标识（`province`/`city`/`region`） | 影响空间分析与省际排序 |
| **P8** | `inferred_flags` 是否登记齐全 | 决定敏感性分析能否做 |
| **P9** | `notes` 是否写清了所有疑问 | 决定后人能否追溯 |

## 3. 逐字段校对动作表

### 3.1 P1：样本量

| 动作 | 判据 |
|---|---|
| 该行是否有独立样本量？ | 若原文只给总样本量，各亚组行**不得填总样本量** → 留空 + `notes` 写"仅报告总样本量 N=xxx" |
| 样本量是否 > 0？ | `0` 或负数 → 该行不可合并，标记待人工确认 |
| 是否存在同一研究多行样本量之和 > 总样本量？ | `WARN`：可能是重复计数（分性别又分年龄，两套拆行相加会超过总数） |
| 是否为"记录数"而非"人数"？ | 若原文报告的是样本份数（如多次采样），需在 `notes` 说明 |

### 3.2 P2：时间

| 动作 | 判据 |
|---|---|
| 是采样/招募年份吗？ | 原文写"数据收集于 2018–2019" → 填 `2018`（或代表年）并在 `inferred_flags` 登记 `time_represented` |
| 是否误填发表年份？ | 若 `time == t_publication`，**逐条回原文确认**（正常研究通常差 1–3 年） |
| 多年区间的代表年怎么取？ | 取起始年或中位年，**取法必须写进 `notes`**；同一项目内取法要统一 |
| 是否全部记录都有时间？ | 该项目要求 100% 齐全；缺失的记录不得用于时间趋势 |

### 3.3 P3：基质与校正

| 动作 | 判据 |
|---|---|
| 血的基质是什么？ | 原文明确"全血" → `WholeBlood`；"血清/血浆" → 对应值 + `flag_blood_matrix=TRUE`；未说明 → `Unspecified` + `blood_matrix_assumed` |
| 尿是否校正？ | 有 `μg/g Cr` → `Creatinine`；有比重校正 → `SpecificGravity`；纯 `μg/L` → `No`；用参考值换算得来 → `ReferenceConversion` |
| 校正单位是否一致？ | `μg/g Cr` 与其他单位不可直接混填 |
| 是否报告了原始浓度与校正浓度两套？ | 优先取校正值，另一套记入 `notes` |

### 3.4 P4：统计量对位

| 检查 | 判据 |
|---|---|
| `stat_type` 与已填列是否自洽？ | 填了 `initial_gm` → `stat_type` 应含 `GM`；只填 `initial_median`+`initial_p25`+`initial_p75` → `Median_IQR` |
| 是否把 AM 填进 GM 列？ | 若原文只有 AM，`initial_gm` 必须留空（S4 会用 Wan 公式估算并标记） |
| SD 是算术 SD 还是几何 SD？ | 原文给 GSD → 填 `initial_gsd`；给算术 SD → 填 `initial_sd` |
| 百分位数标签是否正确？ | P25/P75 是四分位数；P5/P95 是尾部百分位。不要互换 |
| 是否把 Min–Max 当 P5–P95？ | 不允许，二者不同 |

### 3.5 P5：单位

| 动作 | 判据 |
|---|---|
| 是否**原样**抄录？ | 是。`unit_original` 保留原文写法（包括 `ug/L`、`μg/L`、`µg/L` 的不同字符） |
| 是否规范化过？ | **不许规范化**。规范化属于 S4 的职责，且必须留痕 |
| 是否看出量级异常？ | 尿砷 `μg/L` 常见个位到几十；血砷 `μg/L` 常见 0.x–10；若差 10³ 倍，先怀疑单位 |

### 3.6 P6–P7：人群与时空

| 动作 | 判据 |
|---|---|
| 分性别是否拆行？ | 是。`gender` 列标 `Male`/`Female`，`male_n`/`female_n` 对应填写 |
| 分年龄是否拆行？ | 是。按 `population_group` 归类（`Adults`/`Minors`/`Pregnant`/`Elderly`/`Mixed`/`Unknown`） |
| `Mixed` 怎么处理？ | 混合人群且无法拆分 → 标 `Mixed`；EDI 计算会跳过 `Mixed`（生理参数无法确定） |
| 省份写法是否统一？ | 全局统一一种（全称或拼音），不得混用 |
| `city` 是否单值？ | 多市用 `|` 分隔，**不得出现全角逗号**（否则聚类失效） |

### 3.7 P8–P9：推断标记与备注

| 动作 | 判据 |
|---|---|
| 凡非原文直接值，是否都登记？ | **20 项**字典见 `data-contract.md` §6；完整表见 `field_dictionary.md` §8.5；单一来源 `shared/inferred_flags.py` |
| 是否有"该标未标"？ | 例：用了 Wan 公式却没标 `gm_from_mean_sd` → **违规，阻断 GATE-4** |
| `notes` 是否写清了疑问？ | 原文矛盾、亚组不清、单位可疑、取年方式，全部写进去 |

## 4. 校对完成判据（GATE-3 出口条件）

- [ ] `validate_table.py` 无 `ERROR`
- [ ] P1–P5 五项（样本量/时间/基质/统计量/单位）**逐条**核对完毕
- [ ] 所有 `inferred_flags` 登记齐全，无"该标未标"
- [ ] 每条记录 `extracted_by` 改为 `AI+Human`、`verified=TRUE`、`verified_by` 填写
- [ ] `verified=TRUE` 比例达到阈值（进入 S4 允许 ≥90%；进入 S5 主结论要求 100%）
- [ ] `校对日志.md` 记录了每条被修改的字段（原值 → 新值 → 依据）

## 6. 常见争议的处理原则

| 情形 | 处理原则 |
|---|---|
| 原文正文与表格数值不一致 | **以表格为准**，并把正文值记入 `notes` |
| 原文正文与附件数值不一致 | 以附件为准（附件通常是原始数据），记入 `notes` |
| 只有图、没有表 | 标记 `value_estimated_from_figure` **并必须人工复核**；无法可靠读数则留空 |
| 原文单位写错（量级明显异常） | 不擅自改；留原文 + `notes` 标注疑似错误 → GATE-3 人工裁定 |
| 同一研究多篇论文报告同一人群 | 填入相同 `cohort_id`，交 GATE-2/GATE-5 裁决去重 |
| 亚组样本量之和 > 总样本量 | 通常因交叉分组；记 `notes`，去重策略由 GATE-5 决定 |
