# 加权合并方法（Weighting Method）

> **用途**：S5 把标准化后的记录合并为总体水平。本文件定义加权 GM/GSD 的数学、权重口径、分层维度与边界情形。
> **保真声明**：数学逻辑与原项目 R 脚本（`描述性分析_run.R` / `EDI计算_run.R`）**完全一致，只改语言不改算法**。

---

## 1. 数学定义

### 1.1 加权几何均值（WGM）

浓度数据近似**对数正态**，因此合并在对数尺度上进行：

```
ln GM_w = Σᵢ (wᵢ · ln GMᵢ) / Σᵢ wᵢ
GM_w    = exp( ln GM_w )
```

- `GMᵢ`：第 i 条记录的几何均值（S4 的 `gm_summary`）
- `wᵢ`：权重（见 §2）
- 求和范围：当前分层的全部记录

### 1.2 加权几何标准差（WGSD）

```
σ_w  = sqrt( Σᵢ wᵢ · (ln GMᵢ − ln GM_w)² / Σᵢ wᵢ )
GSD_w = exp( σ_w )
```

**用途说明**：`GSD_w` 反映**记录间**的离散度（研究间异质性），**不是**个体内变异。图注必须写明这一点——它决定误差线的解释。

### 1.3 误差线

```
下界 = GM_w / GSD_w
上界 = GM_w × GSD_w
```

**注意**：这是 ±1 对数单位的范围，**等价于 GM_w / e^{σ_w}**，不是 95% CI。若要报告 95% CI，需另行计算（见 §5）。

### 1.4 对数底数

`ln` 与 `log10` 在加权几何均值中**结果等价**（因 `10^x = e^{x·ln10}`，常数在分子分母中约去）。
本工作包统一使用**自然对数**，并在 `project.yaml → weighting.log_base` 声明。

> 原项目两个 R 脚本分别用了 `log10`（描述性分析）与 `log`（EDI）。二者结果一致，本工作包统一为 `ln` 并在此说明差异来源，避免后人误判为口径不一致。

## 2. 权重口径

### 2.1 主口径：样本量加权

```
wᵢ = sample_sizeᵢ
```

**理由**：样本量大的研究对目标人群总体水平的估计更精确；且在浓度 meta 分析中，样本量是**唯一在全部记录上可得的精度代理**（多数研究未报告标准误或方差）。

**声明要求**：方法学部分必须写明"按样本量加权"，不能只写"加权"。

### 2.2 替代口径：逆方差加权

```
wᵢ = 1 / SEᵢ²
```

**何时可用**：记录普遍报告了 SE / SD 且 `n` 已知（`SE = SD/√n`）。
**何时不可用**：多数记录只有 GM 或中位数，无 SD → **不可用**（会只保留少数记录，引入选择偏倚）。
由 `project.yaml → weighting.method` 决定，默认 `sample_size`。

### 2.3 权重的边界处理

| 情形 | 处理 |
|---|---|
| `sample_size` 缺失或 ≤ 0 | 该记录**不可加权** → 从合并中排除并计数（不得默认权重为 1） |
| `gm_summary` 缺失或 ≤ 0 | 同上（对数无定义） |
| 同一研究多行且样本量相同 | 疑为总样本量被复制 → 回 GATE-3 复核 |
| 同一研究多行样本量之和 > 总样本量 | 通常因交叉分组（性别×年龄）→ 记 `notes`，去重策略交 GATE-5 |
| 极端大样本（如 > 10⁶）主导结果 | 输出"单记录权重占比"诊断；占比 > 30% 时报告并交 GATE-5 |

### 2.4 单记录权重占比诊断（必做）

```
max_share = max(wᵢ) / Σw
```

| `max_share` | 判读 | 动作 |
|---|---|---|
| < 10% | 健康 | 正常报告 |
| 10–30% | 需注意 | 结果表加注 |
| **> 30%** | **结果被单条记录主导** | 强制做"剔除该记录"的敏感性分析，写入报告 |

> 这是本项目"36 万参与者"教训的延伸：加权合并中若某条记录的样本量远大于其他记录，合并结果实际上等于该研究的结果。

## 3. 分层维度

| 维度 | 字段 | 说明 |
|---|---|---|
| 基质 | `sample_type` | ★ 首要维度；不同基质**绝不合并** |
| 时段 | `time` → `period_scheme` | ★ 由 `project.yaml` 决定（见 `period_and_region_scheme.md`） |
| 地区 | `region` | 大区 |
| 省份 | `province` | 省份级 |
| 人群 | `population_group` | `Adults`/`Minors`/`Pregnant`/`Elderly`/`Mixed`/`Unknown` |
| 性别 | `gender` | `Male`/`Female`/`Both` |
| 逐年 | `time` | 不做分期，按年 |
| 暴露指标 | `analyte` + `analyte_species` | 跨物质/形态不合并 |
| 血基质 | `blood_matrix` | 全血 vs 血清/血浆 |

**分层输出要求**：每个分层单元必须同时输出
`GM_w`、`GSD_w`、`record_count`、`study_count`、`total_sample_size`、`max_weight_share`。

## 4. 最小样本量规则

| 分层单元记录数 | 处理 |
|---|---|
| ≥ 10 | 正常报告 |
| 3–9 | 报告但标注"基于少量记录，解释谨慎" |
| 1–2 | ★ **不报告为独立结论**；或报告但必须显著标注 |
| 0 | 留白，**不得插值或填补** |

**图注要求**：无数据时期必须在图注说明"该时段无符合纳入标准的研究"，不得画成 0 或虚线连接。

## 5. 可选：加权合并的置信区间

若需报告 95% CI（而非 GSD 误差线），在对数尺度上用**加权均值的标准误**：

```
SE_ln  = sqrt( Σᵢ wᵢ·(ln GMᵢ − ln GM_w)² / ((n_rec − 1)·Σᵢ wᵢ) )
CI_ln  = ln GM_w ± 1.96 · SE_ln
CI     = [exp(CI_ln_low), exp(CI_ln_high)]
```

其中 `n_rec` 为参与合并的记录数。

**声明要求**：必须说明该 CI 反映的是**记录间**变异，不是人群参数的抽样误差。混用二者是常见的方法学错误。

## 6. 正确性检查清单（每次运行必做）

- [ ] 权重之和 > 0；无权重为 0 或负的记录
- [ ] `GM_w` 落在参与记录的 `min(GMᵢ)`–`max(GMᵢ)` 区间内（对数尺度加权均值不可能超出输入范围）
- [ ] `GSD_w ≥ 1`（对数尺度离散度非负）
- [ ] `max_share` 已计算并在 > 30% 时触发敏感性分析
- [ ] `record_count` 与 `study_count` 均已输出
- [ ] 分层单元记录数 < 3 的已标注
- [ ] 无数据时期在图注中说明（未画成 0）
- [ ] `ln` 与配置声明的底数一致

## 7. 与原 R 实现的对应关系

| R（原项目） | Python（本工作包） | 说明 |
|---|---|---|
| `sum(Sample_Size * log10(GM_Summary)) / sum(Sample_Size)` | `Σ w·ln(GM) / Σ w` | 底数不同，结果等价 |
| `10^weighted_log_mean` | `exp(ln GM_w)` | 同上 |
| `exp(sqrt(weighted.mean((log(x) - weighted.mean(log(x), w))^2, w)))` | `exp(sqrt(Σ w(ln GM − ln GM_w)² / Σ w))` | 逐项对应 |
| `Hmisc::wtd.quantile(x, weights = Sample_Size, probs = ...)` | 累积权重法分位数（见 `edi_calculation.py`） | 权重为整数样本量时两者一致 |
| `median(x, na.rm = TRUE)`（未加权） | 未加权中位数 | 保留原行为 |
