# AI 提取提示词模板（Extraction Prompt Templates）

> 用途：S3 阶段用 AI 批量提取文献数据。**提示词的唯一目标是把数据"抄"出来，不是"理解"数据。**
> 本文件提供可直接粘贴的提示词、字段清单、以及反幻觉硬约束。

---

## 0. 三条不可违反的硬约束（每条提示词都必须包含）

1. **不允许自己推测数据**。原文没有的数字，一律填 `未报告`，禁止根据图表趋势、同类研究、常识或正文叙述推算。
2. **不允许把不同统计量混填**。原文报告的是中位数就不能填进均值列；报告 P25–P75 就不能填进范围列。
3. **支撑材料必须单独报告**。若文章有 Supplementary / 附件，必须先说明里面有什么，再决定是否从中提取；不得默默跳过。

---

## 1. 提示词 A：环境样本型研究（土壤/水/食物/空气）

> 适用：研究主体是环境介质浓度（不含人体生物样本）。**在人体内暴露 meta 分析中通常只作为解释变量来源，不作主表记录。**

```
帮我提取这篇文章中的数据：采集样本的国家、省份、市，数据样本类型、样本量、数据采集时间、
样本描述（从哪里采集、采集方法）、检测方法，只采集样本中 {ANALYTE_LIST} 的浓度
（几何平均值、平均值、标准方差、百分位数25、中位数、百分位数75、百分位数95、最小值、最大值），
以及浓度单位。

将金属浓度的数据做一个表格（表头横向）。

如果文章有支撑材料，请告知我支撑材料里的内容是什么。
不允许自己推测数据：原文未报告的项目请填「未报告」，不要根据图表或叙述推算。
```

**替换位**：`{ANALYTE_LIST}` → 本项目目标物质清单，例如 `砷(As)、镉(Cd)、铬(Cr)、铅(Pb)、汞(Hg)、镍(Ni)`

---

## 2. 提示词 B：人群内暴露型研究（血/尿/脐血）★ 主用

> 适用：研究主体是人体生物样本浓度。**这是主表的直接来源。**

```
帮我提取这篇文章中的数据：
1. 研究特征：招募人群的国家、省份、市；样本类型（血液、尿液、脐带血、母乳…）；
   样本量；招募/采样时间（起止年）；招募人群描述与筛选标准；是否队列研究。
2. 检测特征：检测方法；血液样本是否说明全血/血清/血浆；尿液样本是否做了校正，
   校正方式（肌酐校正 / 比重校正 / 未校正），若为肌酐校正请给出单位是否为 μg/g Cr。
3. 浓度数据：样本中 {ANALYTE_LIST} 的浓度——几何平均值、几何标准差、平均值、标准方差、
   百分位数25、中位数、百分位数75、百分位数95、最小值、最大值，以及各自的浓度单位。

要求：
- 将浓度数据做成表格（表头横向，一行一个统计量组）。
- 每个亚组（分性别、分年龄、分地区、分时段）单独一行，不要合并成一个总体值。
- 标注每组数据的样本量；若只报告总样本量而未报告亚组样本量，请明确写出。
- 原文报告了什么统计量就只填什么；未报告的项目填「未报告」，禁止推算。
- 如果文章有支撑材料，请先告知支撑材料里有什么内容，再说明是否包含可提取的浓度数据。
```

## 3. 提示词 C：数据提取复核（第二轮，用于抽查）

> 用途：AI 初提完成后，对已提取结果做**反向抽查**——把提取表给回 AI，让它回原文核对。

```
以下是我从你的论文中提取的数据表（见下方）。请你回到原文逐条核对，只做核对，不要新增推断：

对于每一行，请报告：
- ✅ 正确
- ❌ 错误（请给出原文正确值）
- ⚠️ 原文未明确（请指出原文该处写了什么）

重点核对这 6 个字段：
1. 采样/招募时间（是采样年份，还是发表年份？）
2. 样本类型（血？尿？脐血？）
3. 尿液校正状态与单位
4. 报告的是哪个统计量（GM / AM / 中位数 / 其他）
5. 样本量（该行对应的样本量，不是全文总样本量）
6. 年龄与性别分组

[粘贴提取表]
```

> **注意**：提示词 C 的复核结果**不能替代人工校对**。AI 自查与初提使用同一模型，存在系统性盲区。它的作用是**降低人工校对的工作量**，不是取消 GATE-3。

## 4. 提取表列结构（与 data-contract 对齐）

AI 输出必须落到以下列（完整定义见 `shared/data-contract.md` §3）。提示词中应把这批列名一并给出，让 AI 直接按表头输出。

| 分组 | 列名 | AI 初提是否必填 |
|---|---|---|
| 来源 | `title` `author` `doi` `t_publication` `source_database` | Y |
| 时空 | `time` `time_start` `time_end` `country` `province` `city` `county` | Y（`time` 必填） |
| 人群 | `population` `population_group` `recruit_crowd` `population_desc` `age` `age_mean` `height` `weight` `bmi` `male_n` `female_n` `gender` | Y（`population`/`population_group` 必填） |
| 基质 | `sample_type` `blood_matrix` `analyte` `analyte_species` `detection_method` `qc_reported` | Y（`sample_type`/`analyte` 必填） |
| 统计量 | `stat_type` `initial_gm` `initial_mean` `initial_sd` `initial_median` `initial_p25` `initial_p75` `initial_p05` `initial_p95` `initial_min` `initial_max` `initial_gsd` `unit_original` `sample_size` | Y（`stat_type`/`unit_original`/`sample_size` 必填） |

**AI 不填的列**（由人工或 S4 填写）：
`record_id` `study_no` `cohort_id` `dedup_group` `flag_*` `inclusion_decision` `exclusion_reason` `adjusted` `unit_final` `gm_summary` `gsd_summary` `conversion_path` `conversion_params` `inferred_flags` `extracted_by` `verified` `snapshot_tag` `row_hash`

## 5. 多文献批处理模板

> 一次处理多篇文献时，强制"一文一表 + 统一表头"：

```
我将依次提供 N 篇文章。请对每一篇分别输出一张表，表头完全一致（使用我给出的列名）。
每篇文章之间用分隔线「===== 文章编号：X =====」隔开。
不要跨文章合并或比较数据。
如果某篇文章无法提取（例如是综述、动物实验、非人体样本），请在表前写一行「不可提取原因：…」，
不要编造数据。
```

## 6. AI 输出的自检提示（追加在提示词末尾）

```
输出前请自检：
1. 是否有任何数字是原文没有、我推算出来的？如果有，请删除并改为「未报告」。
2. 是否有把总样本量填到亚组行？如果有，请改为「未报告」并注明「仅报告总样本量」。
3. 是否把发表年份填进了采样时间？请核对。
4. 血液样本未说明全血/血清/血浆时，是否如实填「未说明」而不是默认「全血」？
5. 是否所有分亚组数据都单独成行，而不是只给了合并值？
```

## 7. 已知失败模式（来自实证，务必在提示词中防御）

| 失败模式 | 表现 | 防御写法 |
|---|---|---|
| 时间字段误取 | 用发表年份代替采样年份 | 明确"招募/采样时间，不是发表时间" |
| 基质混填 | 血清/血浆当作全血 | 要求"明确写出原文用的是哪种基质，未说明则写未说明" |
| 校正状态丢失 | 尿砷未记录是否肌酐校正 | 单独设问校正方式与单位 |
| 统计量错位 | 中位数填进均值列 | 逐列点名统计量类型 |
| 样本量污染 | 总样本量填进亚组行 | 要求标注"该行对应的样本量" |
| 静默跳过附件 | 未提及 Supplementary | 强制"先告知支撑材料内容" |
| 跨研究混淆 | 把 A 文方法与 B 文数据混在一起 | 多文批处理时强制分隔与"不跨文合并" |
| 图表读数 | 从折线图估读浓度 | 明确禁止，要求填「仅图无表」 |
